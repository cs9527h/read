## 仓库与独立性

- 当前已有**独立的** GitHub 仓库 `cs9527h/read`，原先是 **private**。它不是 Mate/AstrBot 仓库，也不应复制 Mate 的服务端数据。
- 用户明确希望 Read **public**。当前可用 GitHub 连接仅有代码、分支和 PR 相关操作，**不能修改 repository visibility**；必须由仓库管理员通过 GitHub Settings → General → Danger Zone → Change repository visibility → Public 操作。公开前检查所有提交历史、标签、文件与许可证；不仅检查当前工作树。
- `main` 在本次核验时 HEAD = `1338c54e0680bbd2500b573c15db27b95885be83`（P1.1）。已有 `LICENSE`（MIT）。
- 上传的源码包和远端树具有相同的代码结构；文档压缩包中的两份中文项目设计文档尚未加入仓库，未经进一步确认不自动公开未提交的内部资料。

## 代码实际支持 / 限制

| 功能 | 实际判断 |
|---|---|
| TXT 文件导入 | 有文件选择、应用目录副本、UTF-8 BOM/GB18030 解码路径；尚需手机端验证 |
| 书架和进度 | 本地文件 + SharedPreferences 保存元信息、按章节/页保存进度；**不是 SQLite** |
| 分章 | 标题正则 + `splitChapters`；原 GitHub Actions 跑过分章单测 |
| 分页 | `TextPainter` 按行测量；只有普通短行测试；目前整章计算，非按字符分块，超长单行可能超屏 |
| 墨水屏 | `--dart-define=EINK=true` 控制纯黑白、禁页面转场动画，尚无 E-Ink 真机刷新 API 适配 |
| EPUB / PDF / 漫画 / DOCX / 听书 / 同步等 | 均未实现；不得标记已完成 |
| 按字号重新分页保留定位 | 目前锚点使用页号，字号变化后可能漂移；后续应迁移至稳定的字符偏移 |
| 超大 TXT | 导入和初始化仍可将全书读入内存，超过 50MB 的大书优化未实装 |
| 完整平台骨架 | CI 临时 `flutter create` Android 目录，不是完整独立持久化 Android 平台壳 |
| 完整多端 CI | Windows / 正式 release/signing 尚未实现 |

两个上传 APK 的二进制 AndroidManifest **均包含包名 `app.readen.read`**、版本 `0.1.0`。故原版两 APK **不能同时安装为两个独立 App**，文件哈希不同只说明构建内容不同。没有通过 APK 签名证书校验、Android 手机/墨水屏真机安装验收；这两个 APK 不应冒充最新修复版。
