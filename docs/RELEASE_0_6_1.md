# Read 0.6.1+9 阅读体验预览版

版本：`0.6.1+9`，包名 `app.readen.read` / `app.readen.read.eink`，签名沿用固定预览签名。

## 本轮改动

- 书架卡片、标题区域与列表整行点击直接进入阅读页；书籍详情移入长按菜单。
- 阅读页 PageView 末页增加“下一章”哨兵页，左滑自动进入下一章；滚动模式滚到底、点击下一章同样跨章。
- 阅读页同步面板重做：本机进度、云端进度、设备与更新时间、同步本机、采用云端、完整同步、云存储与同步范围入口。
- 顶栏同步图标真实反映云端状态：未配置、云端无记录、云端有不同进度、已一致、读取中转圈。
- 新设备开书自动读取云端进度；冲突默认询问，不静默覆盖。
- 阅读进度可在移动网络同步，图书文件仍遵守“仅 Wi-Fi”。
- 同步设置补充 WebDAV 兼容网盘（坚果云/Nextcloud/AList/群晖）与 S3 兼容说明。
