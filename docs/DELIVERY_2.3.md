## 二、如实记录的限制（未验证 / 未实现）

- **跨设备密钥迁移**：仅做到「局域网内经临时令牌传递密钥」的自动化验证（真实 TCP）。两台真机、二维码/一次性链接授权形式未做真机联调。
- **S3 多服务商**：条件请求降级在模拟服务上验证通过；AWS/R2/B2/MinIO 真实账号仍未联调，标记为待真实账号验证，未虚构通过。
- **数据同步覆盖审计结果（不虚报）**：
  - 已同步：阅读进度、书签、高亮、阅读设置（默认关）。
  - 部分：书籍文件（默认关）、书籍元数据（缺分类/收藏/置顶/评分/阅读状态）、阅读器主题（随设置）、阅读统计（仅上传未落地）。
  - 未同步：独立「笔记」实体（现仅作为书签/高亮内 note 字段带出）、App 外观主题（themeMode/字体缩放/uiMode）。
- **局域网设备发现**：仍采用对端复制共享链接/输入地址方式，未实现 UDP 广播自动发现；手动连接不受影响。
- **真机项**：WebView 封面搜索图片抓取/裁切、双设备同步、Android 7 实机、帧率/内存，均需真机确认。
- 既有未完成项保持不变（PDF 标注、EPUB CSS/脚注、CBZ/CBR、FB2/MOBI/AZW3、词典翻译、AI、云书库等）。
- 签名仍为公开预览密钥，正式分发前必须替换并规划覆盖升级。

## 三、约束保持

单 APK `app.readen.read`；内置墨水屏（运行时切换，无独立包）；minSdk 24（Android 7.0）；
升级兼容（旧 SharedPreferences 键与旧密码保留）；每批独立提交可回滚；不硬编码真实云密钥；
日志不输出 Access Key / Secret Key / 共享令牌 / 同步密钥。
