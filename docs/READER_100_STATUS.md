# Read 阅读内核 100 项交付状态（v0.4.0-preview）

本表按上传的《100 项阅读界面自定义需求》逐条核对。状态只写实际情况，不把“写了代码”当成“真机通过”。

状态口径：

- **已完成·单测**：有自动化测试覆盖的核心逻辑。
- **已实现·未验证**：代码已接入正文并可操作，尚未在真机逐项验收。
- **部分完成**：主路径可用，但有明确缺口（表内写明）。
- **未完成 / 受平台限制**：没有实现，或当前工程结构下无法实现。

## 统计

- 已完成·单测：7 项（01、91–94、96–98 中的核心项）
- 已实现·未验证：约 60 项
- 部分完成：约 28 项
- 未完成 / 受平台限制：仍包括 EPUB 图片/CSS、60、70、73，以及 79 的音量键等缺口；85 已补代码但未做真机验收

> 结论：这次交付的是**可运行的真实阅读内核 + 完整设置面板 + 分级存储**，不是演示页。仍缺 EPUB 富文本渲染、仿真翻页、信息块拖动、底部菜单排序、音量键、真机逐项验收；这些在表里明确标出，没有伪装成完成。


## v0.4 阅读稳定性修复（PR #23，尚待最终 CI 验证）

- 修复重启后单本书覆盖配置未读取的问题；新增跨重启隔离测试。
- 修复编辑全局设置时把本书独立排版误写到全局的问题。
- 对导入 JSON 的各层设置进行写入前校验，避免错误类型破坏阅读器。
- 设置写入队列防止快速滑块操作造成顺序倒置。
- 后台暂停阅读时间统计及自动翻页，后台保存当前阅读进度。
- 阅读定位与超长章节分页采用二分/指数探索，减少不必要的全文测量。
- 字体通过 Android 文件读取流导入，限制大小并检验格式和加载结果。
- 阅读设置中加粗规则输入控制器保持稳定，底部快捷操作可自定义顺序。
