# Read 0.6.2+10 · 长期使用改造批次

日期：2026-11-16（UTC+8）
版本：`0.6.2+10`
包名：`app.readen.read`（普通版）/ `app.readen.read.eink`（墨水屏版）
签名：沿用固定预览签名，不更换证书。

## 本批次实际改动

### 1. 入口收敛：删除“我的”和继续阅读中转
- 底部导航改为 **书架 / 统计 / 同步 / 设置** 四栏，`ProfilePage` 更名为 `SettingsPage`，移除头像、“我的书房”和重复同步入口。
- 书架删除继续阅读卡片及其候选计算，不再保留“继续阅读”中转页；点击书籍封面或标题直接进入阅读器。
- 阅读历史页标题从“我的阅读”改为“阅读历史”。

### 2. 图标区分
- 新增 `tools/android/generate_icons.py`，生成两套真实 PNG：
  - 普通版：深色实底、细描边、完整羽毛与羽枝。
  - 墨水屏版：白底、单线边框、细线空心羽毛，减少装饰。
- `tools/android/apply_icons.sh` 支持 `eink` 参数；`release.yml` 与 `build-android.yml` 在墨水屏构建前重新应用独立图标，两个 APK 不再共用同一套 launcher 图标。
- 应用内 `ReadIcons` 把统计、同步、设置、搜索、更多、编辑、书、云、标签、文件夹等改为普通版实心/完整轮廓、墨水屏细线/空心两套映射。

### 3. 书架右上角总菜单
已落地：选择、WiFi 传书、从本机导入、扫描文件夹、智能导入、创建书箱/分组、书架设置、标签管理、分类管理、书籍排序、更多。
- 选择：进入多选，批量删除本机副本，明确提示云端对象不受影响。
- 扫描文件夹/智能导入：递归扫描，支持 EPUB/TXT/MD/HTML/PDF，单次最多 200 个文件，按真实路径导入并跳过不支持或空文件。
- 创建书箱：新增本地分类并持久化；书架增加分类筛选行；编辑书籍时可归入。
- 书架设置：网格/列表、列数（自动/3/4/5）、是否显示进度，写入 SharedPreferences。
- 标签管理：统计全部标签，支持重命名、从所有书中删除。
- 分类管理：合并自定义分类与书籍分类，支持重命名、清空分类。
- 书籍排序：最近阅读、书名、作者、导入时间，置顶书始终优先。
- WiFi 传书：内置局域网 HTTP 接收页，手机与电脑同一 WiFi 时用浏览器上传；地址带 40 位随机令牌，仅接收 EPUB/TXT/MD/HTML/PDF，单文件上限 64MB，上传后走与文件选择器相同的校验/哈希/入库流程；停止接收立即关闭端口，不开放目录浏览。

### 4. 单书菜单与编辑信息
- 单书菜单：阅读、信息、编辑信息、置顶/取消置顶、分享、导出原文件、分类、更多、移除。
- 更多：标签、阅读状态、复制文件路径。
- 编辑信息页 `book_edit_page.dart`：
  - 字段：书名、作者、分类、评分（0–5）、置顶、私密、阅读状态（未读/在读/搁置/读完/弃读）、标签。
  - 封面：预置模板（本地 Canvas 生成黑白 PNG）、本机图片、网络图片（仅 http/https，限制 10MB）、查看大图、保存封面。
  - AI 生图与搜图明确标注“未接入”，禁用点击，不伪造成功。
  - 保存统一调用 `LibraryStore.updateBookInfo`，失败回滚并提示。
- 书架封面支持 `coverPath` 真实图片；私密书只隐藏书架标题/文字封面书名，不加密内容、不加隐私锁。
- 分享当前复制书名、作者、文件路径到剪贴板，并明确提示系统分享面板尚未接入。

### 5. 云端状态真实化
- 新增 `CloudLibraryIndex`：只读云端 `metadata.enc` 与 `files/` 列表，按 64 位内容哈希建立索引并持久化。
- 书架云朵只在真实云端存在该书元数据或文件时显示；未配置、同步失败、索引为空时不显示装饰性云朵。
- 全量同步成功后刷新索引；同步页“更多 → 刷新云端书库状态”可手动只读刷新，失败保留上次成功索引。
- `MetadataSyncService.readRemoteSnapshot` 提供只读云端快照，不写入、不合并。

### 6. 同步数据迁移
同步页新增“数据迁移”Tab：
- 导出本机设置：阅读排版、主题/外观、同步偏好（不含密码、密钥、加密口令）。
- 导入本机设置：校验 JSON 类型与版本，恢复阅读设置和外观。
- 从其他设备恢复：确认后拉取云端元数据与缺失文件，按修改时间合并，不覆盖本机较新进度。
- 云端数据对比：只读 `metadata.enc`，按书籍/书签/设置/统计/进度类型对比本机与云端数量；解密失败只报告错误。

### 7. 阅读流畅度
- 分页缓存：以尺寸、双栏、字号缩放、完整排版设置、章节索引与章节长度为键；最多 6 章，超出淘汰最早缓存。
- 相邻章节预加载：当前章排版完成后，在帧结束回调中预排版前后各一章，不插入零延迟 Timer。
- 切换章节时若命中缓存，立即复用分页并定位到目标页，减少空白帧。
- 页码变化改用 `ValueNotifier<int>` 驱动页眉页脚，翻页不再对整页 `setState`；章节切换和重新排版仍保留必要的整页重建。
- 墨水屏主题/路由无动画策略保持不变。
