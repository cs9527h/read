# read

> **状态（2026-11-15）**：GitHub 仓库现已公开；项目仍在积极开发中。书架/统计/我的三栏新版 UI 在 PR #17（v0.3.0-preview）中重做，已移除内置示例书。PDF、加密 WebDAV、SQLite、Windows 构建仍待独立验证，不能作为已发布功能。正式 APK 发布前仍需验证构建、签名、升级与真实设备安装。


极简全平台电子书阅读器。目标：**阅读相关功能完整保留 + 多端同步**，去掉主题商店、装饰特效、社交与会员广告。

- 平台：Android（手机）、Android（墨水屏平板独立包）、Windows
- 技术栈：Flutter 单仓多目标
- 构建：全部通过 GitHub Actions 完成（无本地 Flutter/Android SDK 环境）

## 版本与发布

当前预览版：**v0.3.0 preview**（`version: 0.3.0+3`，新版三栏 UI）。打 `v*` 标签会触发 `.github/workflows/release.yml`，自动构建两个 APK 并附到 GitHub Release，同时上传 `APK_SHA256.txt`。

CI 使用内部测试签名，不是正式发布签名；正式覆盖升级前必须换成固定的 keystore。

## 构建

推送 `main` 或手动触发 `.github/workflows/build-android.yml`，产物为两个 APK：

- `read-android.apk`：普通 Android 版
- `read-eink.apk`：墨水屏版（`--dart-define=EINK=true`）

## 本轮开发验证范围

- [P2.0 阅读兼容与同步内核报告](docs/P2_0_COMPAT_SYNC_20261115.md)
- EPUB 目前是阅读顺序上的**文本提取**，不是 EPUB3 复杂图文版式引擎；不能展示 EPUB 图片、富格式表格或 DRM 内容。
- 同步模块目前只是冲突规则原型和测试；**绝不上传阅读数据到云端，也不假称已具备多设备同步**。

## TXT 一等支持（P2.1，开发分支）

TXT 是 Read 的长期核心格式，**不会因为增加 EPUB/PDF 就删减功能**。

已提交但必须经 CI 和真机复核：UTF-8 / UTF-8 BOM / GB18030 兼容；新增 UTF-16 LE/BE BOM；连续长段落（不依赖换行）测量分页；源文本范围精确分页，保留重复行、空行、表情符号和当前章节字符偏移；章节识别不吞前一行换行符且跳过过长假标题。详见 [TXT 专项检查](docs/TXT_CORE_P2_1.md)。

**尚未完成：** 40 MB 以上 TXT 分块索引与按需读取（当前先安全拒绝而不是冒险耗尽内存）、自定义正则/内容替换/人工修章、书籍位置 SQLite 事务与跨设备 WebDAV 双向同步。旧版本阅读进度需要按真实设备验证迁移。原有 TXT 导入文件不会因新增 EPUB 功能被强行转换或删掉。

## WebDAV 阅读进度双向同步（PR #15，开发分支）

正在实现手动触发的加密阅读进度同步：按源文件 SHA-256 识别同一本书，文本使用绝对 UTF-16 字符偏移并检查解析后文本摘要，PDF 使用页码；WebDAV 上传使用 ETag 条件提交，遇到冲突由用户选择。新设备导入相同文件后可拉取已有云端进度；对无法确认的旧版页码位置不会自动覆盖。

**状态：待 GitHub Actions、真机以及跨设备验收，未合并、未发布。** 目前不传书籍文件、书签、笔记、设置，也没有开启后台自动同步或凭据持久保存。不要把这个开发分支当作 Reeden 完整同步功能。

验证和限制见 [WebDAV 进度同步说明](docs/WEBDAV_PROGRESS_V1.md)，完整的 Reeden 同步能力缺口和验收目标见 [同步对标清单](docs/REEDEN_SYNC_PARITY_PLAN.md)。
